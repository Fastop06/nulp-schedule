## 🚀 Основні можливості

### 🔔 1. Розумні сповіщення про розклад
* **За 30 хвилин:** надсилається перед **першою парою дня**, а також **після вікон** (якщо між парами перерва > 20 хв).
* **За 5 хвилин:** надсилається перед **кожною парою безпосередньо**, щоб встигнути підключитись або зайти в кабінет.
* **Повна інформація:** назва предмету, скорочені ініціали викладача, тип заняття (лекція, практика, лаба), аудиторія, корпус та лінк на Google Maps.

### 📝 2. Завдання, Домашка та Дедлайни (TODO)
* Зручне додавання завдань через покроковий майстер або швидкі кнопки.
* Вибір предмету зі списку або введення власного.
* **Гнучкий парсер дедлайнів:** розуміє фрази на кшталт `завтра 18:00`, `сьогодні 23:59`, `через 2 дні 15:00`, `п'ятниця 23:59`, `15.09 20:00`.
* **Багаторівневі нагадування про дедлайн:**
  * За 48 годин (2 дні)
  * За 24 години (1 доба)
  * За 3 години
  * За 1 годину
  * За 15 хвилин
* Інтерактивні кнопки `✅ Виконано` / `↩️ Відновити` / `🗑 Видалити`.

### ⏳ 3. Live-статус «Зараз / Наступна»
* Показує поточну пару та таймер зворотного відліку до дзвінка.
* Якщо зараз перерва або вікно — показує зворотний відлік до початку наступної пари.

### 🌅 4. Ранковий та Вечірній дайджести
* **Ранковий огляд (07:30):** повний розклад на день + список гарячих завдань.
* **Вечірній огляд (21:00):** розклад на завтра + нагадування про домашку.

### 🏛 5. База викладачів, корпусів та матеріалів
* Каталог навчальних корпусів (`I н.к.`, `VII н.к.`, `XX н.к.`, `Самчука 21`) з точними адресами та лінками на мапу.
* База викладачів кафедри (з лаконічними ініціалами).
* Нотатки/конспекти (`/notes`, `/add_note`) та розумний пошук по розкладу (`/find <запит>`).

## 📁 Структура проєкту (Flat All-in-One)

```
schedule_bot/
├── main.py               # Все-в-одному: бот, розклад, база даних SQLite, планувальник, обробники
├── .env                  # Токен бота та конфігурація
├── requirements.txt      # Залежності (aiogram, aiosqlite, pytz тощо)
├── start_bot.sh          # Скрипт запуску в один клік
├── README.md             # Повна документація
├── index.html            # Web App інтерфейс (Tailwind CSS, Glassmorphism)
├── app.js                # Web App логіка (розклад, дедлайни, фільтри, база викладачів)
├── style.css             # Web App стилі та анімації
├── vercel.json           # Конфігурація для розгортання на Vercel
├── crash_test.py         # Повний стрес-тест парсера, бази даних та екранування HTML
└── test_handlers.py      # Симуляційні тести всіх FSM та колбеків aiogram 3
```
